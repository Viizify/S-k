## Nedlasting

- **Alt på ein gong:** grøn knapp «Code» → «Download ZIP».
- **Éi fil:** klikk på fila → nedlastingsikonet («Download raw file») øvst til høgre.

Filene kan importerast direkte i Rayyan, Zotero, EndNote o.l.
